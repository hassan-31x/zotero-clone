# Margin design system
Researchers read long papers on a bright desktop beside their notes, so light warm surfaces reduce visual noise and keep the PDF central.
Use Geist, a restrained neutral palette, near-black text and amber for primary actions. Use 12/14/16/20/24/30px type, 4/8/12/16/24/32/48px spacing, 8px controls and 12px panels. Sidebar 232px, header 64px. Borders separate functional panes; cards are only for documents and reading entries. Dark theme retains subdued surfaces. Motion is limited to hover and state changes, respecting reduced motion.
